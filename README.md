# VELTHON Student Hub — website address on GitHub

The Student Hub website runs on Cloudflare: https://vsh.velthond.workers.dev/

This repository only keeps the GitHub address (https://velthond.github.io/velthonSH-c/) working. It sends
visitors straight to the live site, so the GitHub address always opens the latest version and never needs
rebuilding. The code lives in the private repository velthond/Velthon-Student-Hub; Cloudflare builds and
publishes the website from it on every change.
